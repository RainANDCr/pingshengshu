# 平生述 · Windows / Android / 网页版

> 人生有迹，岁月成书。
> AI 人生回忆录 · 单文件零依赖内核，三端（网页 / Windows / Android）共用同一份 `index.html`。
> 当前版本：**V3.0.0**（含人生足迹、人物簿、碎片箱、专题集等完整功能）

## 在线访问与下载

- **网页版（GitHub Pages）**：<https://rainandcr.github.io/pingshengshu/>
- **Windows 便携版**：<https://github.com/RainANDCr/pingshengshu/raw/main/release/平生述-3.0.0.exe>
- **Android 安装包**：<https://github.com/RainANDCr/pingshengshu/raw/main/release/平生述-3.0.0.apk>

> 数据默认保存在本机（IndexedDB），不随浏览器/设备同步；跨设备迁移请用应用内「导出 / WebDAV 云备份」。

## 使用说明

### 1. 快速上手

1. 打开应用，进入「我的」→「出生日期」，填写生日。系统据此自动计算每段回忆的年龄，并生成 1~70 岁的年龄书架。
2. （可选）进入「我的」→「AI 模型设置」，填入你自己的模型服务商 Key（BYOK，密钥仅存本机）。启用后可体验 AI 润写、AI 序言、AI 整理等能力；不填也不影响日常记录。

### 2. 记录一段回忆

- 点「记录」，填写标题、正文、事件日期（也可只填「约几岁」）、地点、标签。
- 支持插入多张图片（自动压缩）、录制一段语音。
- 保存后，回忆会自动按年龄归档到「书架」，并出现在「时光」时间轴。

### 3. 八大模块

| 模块 | 用途 |
|---|---|
| 首页 | 今日回忆唤醒、最近记录，以及「记忆拾遗 · 碎片箱」入口 |
| 记录 | 新增 / 编辑 / 删除回忆，支持图片、录音、标签、年龄 |
| 书架 | 1~70 岁年龄书架 + 专题书架（自建主题合集，如「学生时代」「旅行故事」） |
| 时光 | 按时间轴浏览全部回忆，支持搜索与标签筛选 |
| 足迹 | 地点地图与列表，回忆 ↔ 地点双向关联 |
| 人物 | 人生人物簿，记录重要的人、相识地点与共同回忆、照片 |
| 期许 | 岁岁有期 · 年度目标 |
| 我的 | 出生日期、AI 设置、导出备份、WebDAV 云备份、隐私政策 |

> 「记忆拾遗 · 回忆碎片箱」入口在首页：随手记下零散的瞬间，之后可合并、整理成正式回忆。

### 4. AI 功能（BYOK，可选）

- **回忆唤醒**：基于已有回忆，生成个性化的提问。
- **AI 润写**：5 种风格改写回忆，前后对照，可接受 / 复制 / 放弃。
- **AI 人生序言 / 专题序言**：勾选回忆范围后生成序言。
- **AI 整理成故事**：把多片碎片整理成一篇完整回忆。
- 所有 AI 调用均需你确认发送范围，密钥不上传、不写入任何导出文件。

### 5. 数据保存与迁移

- 所有数据默认保存在本机（浏览器 IndexedDB），断网可用，不会自动上传。
- 「我的」→「导出与备份」支持导出 TXT / PDF / ZIP / JSON。
- 「我的」→「WebDAV 云备份」可同步到你自己的网盘（坚果云 / Nextcloud 等）。
- 换设备时：旧设备「导出」→ 新设备「导入」；或使用 WebDAV 上传 / 恢复。

## 一、桌面网站（即开即用）

直接双击打开 `index.html`，或启动本地服务：

```
cd 平生述
npx serve .        # 或 python -m http.server 8080
```

桌面宽屏自动显示左侧书卷导航，窄屏/移动端自动切换为底部导航。

## 二、Windows 版（生成 exe）

需要 Node.js 18+：

```
cd windows
npm install
npm start                # 开发预览
npm run pack:win         # 打包出 portable exe / NSIS 安装包（dist 目录）
```

数据通过 Electron 的本地存储保存在用户数据目录，随应用保留。

## 三、Android 版（生成 APK）

需要 Android Studio + JDK 17：

```
cd android
npm install
npx cap add android      # 首次执行，生成 android/ 原生工程
npx cap sync
npx cap open android     # 打开 Android Studio → Build APK
# 或命令行： cd android && gradlew.bat assembleDebug
```

APK 输出于 `android/app/build/outputs/apk/debug/`。
修改网页内核后，请同步更新 `android/www/index.html` 并重新 `npx cap sync`。

**正式签名包（release）**：在 `android/android/` 下用 keytool 生成签名密钥、创建 `keystore.properties`（两者均不入库），再执行：

```
# 生成密钥（一次性）
keytool -genkeypair -v -keystore pingshengshu-release.keystore -alias pingshengshu \
  -keyalg RSA -keysize 2048 -validity 10000

# 配置 keystore.properties 后构建
cd android/android
gradlew.bat assembleRelease
```

产物：`android/android/app/build/outputs/apk/release/app-release.apk`。**务必妥善保管 keystore 与密码**，后续升级必须用同一密钥签名才能覆盖安装。

- **人生专题集（阶段一 · 专题书架与编排闭环）**：书架页新增「年龄书架 / 专题书架」切换（原年龄书架行为不变）；专题书架按封面卡片展示书名 / 简介 / 章节数 / 篇数 / 作者 / 更新时间，空状态引导创建；**创建 / 编辑 / 删除确认**（书名必填、副标题、作者署名、封面色调、专题简介、序言、尾声）；**章节管理**（新增 / 重命名 / 删除 / 上下排序）；**从回忆库多选加入文章**（按年份 / 年龄 / 标签 / 关键词过滤，勾选加入、章内去重）；**文章排序与移除**（移出专题不删回忆，同一篇可收进多本专题书且不复制正文）；**复用原阅读器**（点文章进 `ViewMemory`，支持「返回专题」与章内上 / 下一篇导航）；删除专题只移除章节与引用、不删任何原始回忆；删除回忆后专题显示「该回忆已删除」占位不崩溃
- **人生专题集（阶段二 · 模板、检索与精细编排）**：**专题模板**（自定义 / 学生时代 / 旅行故事 / 家庭回忆 / 友情故事 / 成长记录，选择后仅填充默认章节 + 封面色调 + 副标题 / 简介占位，可完全编辑）；**自定义封面**（上传图片自动压缩、覆盖封面色调，可移除，书架卡片与详情 hero 均显示）；**高级筛选**（回忆库选择器新增人物 / 足迹下拉，有数据才可选、空则禁用提示）；**规则筛选模式**（手动编排 / 规则筛选切换，按标签 + 年份区间 + 年龄区间 + 人物 + 足迹 + 内容关键字检索候选，实时预览命中数量，「待收录」逐篇手动收录、可关闭规则，不后台改写已编排目录）；**阅读进度**（独立 `thematicProgress` 集合，书架卡片显示进度条、详情页「继续阅读」、目录已读 ✓ 与「读到这 ▶」标记，不与年龄书架互相覆盖）
- **人生专题集（阶段三 · 导出与 AI 序言）**：**专题书导出**（详情页「导出与序言」卡片提供 TXT / PDF / ZIP 三种真实导出；TXT 按封面 / 副标题 / 作者 / 序言 / 目录 / 章节正文 / 尾声顺序导出；PDF 复用打印版式含封面 / 序言 / 目录 / 章节正文 / 图片；ZIP 含 manifest（专题类型与计数）+ 专题结构 JSON + 每篇正文 txt + 附件按 `memoryId` 去重仅存一份 + 引用清单 txt，内容快照防导出中正文被改，绝不包含密钥）；**AI 撰写序言**（`tbook-ai` 路由：勾选要发送的回忆（同一篇跨章节只显示一次）、风格「温柔回忆 / 文学散文 / 真实朴素 / 自定义」、发送前第三方费用确认、结果进入可编辑草稿，采用后才覆盖序言并写入 `thematicPrefaceVersions` 历史版本；AI 提示词约束不编造 / 不虚构，无 Key 早退）；删除专题时同步清理序言版本与阅读进度；空章节与「该回忆已删除」占位均正常导出不崩溃
- **人生专题集（阶段四 · 三端性能、安全与发布验收）**：**海量目录性能**（重构目录渲染：`thematicFlat` 一次性构建扁平阅读序列 + `idxOf` Map 索引，消除原「每章重复计算全书进度」的 O(章² × 篇) 复杂度，50 章 × 500 篇目录一次渲染 <1.5s、进度快照精确到「读到第几篇」）；**长文与附件**（5 万字长文正文正常渲染；正文图片 `loading="lazy"` + `decoding="async"` 懒加载，降低多图长文首屏负担）；**离线与跨用户隔离**（专题集纯本地 IndexedDB 存储，零网络 / 远程加载依赖，断网可用；本地单用户数据天然隔离，无跨账号访问面）；**旧数据迁移**（`normalizeDb` 非破坏性补齐旧专题书缺省字段 bookType/editorMode/coverColor/templateId/settings 与新增集合，旧书不被误识别）；**删除关系**（删除专题只移除章节 / 引用 / 规则 / 进度 / 序言版本、不删任何回忆；删除回忆后目录与导出均显示「该回忆已删除」占位不崩溃）；**三端验收**（Web / Windows EXE / Android APK 共用同一内核，构建与运行路线见下，无小程序 API 依赖）



## 真实能力 vs 演示模式

BYOK AI 已实现**客户端直连**（真实调用你配置的模型服务商）：连接测试、AI 润写、AI 序言均为真实请求，Key 通过 HTTPS 直发服务商，不写入日志/导出文件/仓库。若服务商禁用浏览器 CORS，请改用兼容服务或后续的后端代理。

以下能力仍为**演示 / 待接入**：

| 功能 | 现状 | 计划阶段 |
|---|---|---|
| 官方多端云同步（账号） | WebDAV 备份可跨设备；账号同步待接 | 第三阶段（CloudBase） |
| 未来信件到期解锁 | 本机日期判断 | 第五阶段改为服务端可靠时间源校验 |
| 密钥服务端隔离 | 客户端直连 | 生产化前接入可信服务端适配器 |
| Android 一键定位 | 已声明定位权限；`navigator.geolocation` 在已授权/支持时可用，否则降级城市检索 | 需 `@capacitor/geolocation` 插件触发运行时授权（见下） |

> **地图数据说明**：地图瓦片来自 OpenStreetMap（需署名），地点检索/逆地理编码使用 Nominatim（免密钥，返回 WGS84）。两者均为免费公开服务，覆盖与精度对中文 POI 有限，商业级中文检索需自行接入高德/腾讯等带 Key 服务（密钥不得写入源码/导出包）。离线时地图自动降级为本地列表。

> **Android 定位**：已在 `AndroidManifest.xml` 声明 `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`。若要支持首次点击「我的位置」时弹出系统授权框，需在 `android/` 下执行 `npm i @capacitor/geolocation` → `npx cap sync` 并重新构建 APK；未接入时 WebView 的定位在未授权环境会降级为城市检索。

## 隐私说明

回忆、信件、足迹地点、人物档案、记忆碎片、AI 配置默认保存在本机（IndexedDB）；可选 WebDAV 云备份存于你自有的服务器。导出与云端备份文件自动剔除 AI 密钥与 WebDAV 密码。AI 调用仅在你明确确认、且限定勾选内容范围后发送至所选模型服务商。足迹坐标由用户自行填写或地图选点，未知位置不伪造经纬度，不持续跟踪实时位置；地图视图按需联网加载瓦片，离线自动降级为本地列表。人物档案涉及第三方个人信息，默认仅创建者本机可见，不做人脸识别、不读取通讯录，人物名/头像不自动加入 AI Prompt 或公开分享。记忆碎片为本人私密记录，事件日期未填写时不以记录时间冒充，碎片转正式回忆仅在用户显式保存后创建。

## 三端验收路线

- **Web**：`index.html` 为无构建单文件，直接浏览器打开或任意静态托管即可运行；跨设备数据默认保存在本机 IndexedDB（不随浏览器同步），需用 WebDAV 备份跨设备迁移。
- **Windows EXE**：`windows/` 下 Electron 工程，`npm install` 后执行 `npm run pack:win`（需 `win.signAndEditExecutable:false` 并设 `ELECTRON_BUILDER_BINARIES_MIRROR` 镜像）产出便携版 exe。
- **Android APK**：`android/` 下 Capacitor 工程，`npm install` → `npx cap sync` → `./gradlew assembleDebug`（需 JDK17 + Android SDK，走 aliyun maven 镜像）；一键定位需额外接入 `@capacitor/geolocation`。
- 三端共用同一 `index.html` 内核（`windows/index.html` 与 `android/www/index.html` 为同步副本），改功能只需改根目录 `index.html` 再同步。
